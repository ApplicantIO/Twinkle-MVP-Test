# Project Brief

## Project

Twinkle-MVP-Test is a Next.js monolith for short/long-form video discovery, watch flows, creator publishing, and monetization demos.

## Primary Areas

- Viewer experience: feed, search, watch page, history, playlists, profile/library
- Creator studio: upload and manage videos, channel profile
- Monetization demo: simulated payment/purchase flows

## Core Requirements

- Preserve current architecture and layout ownership
- Keep auth and authorization aligned to existing role model
- Favor additive and backward-compatible changes
- Maintain small, reviewable diffs
